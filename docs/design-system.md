# AgentMate 设计系统速查

> 面向在本仓库写 UI 的迭代记录与代理。完整方案与背景见 [ui-refresh-plan.md](ui-refresh-plan.md)，迭代记录见 [iteration-log.md](iteration-log.md) 第二百零七——二百一十一轮。

## 设计原则

1. **四级表面**：`background`（画布）→ `surface-1`（侧栏）→ `card`（卡片/执行组）→ `elevated`（浮层/hover 行/弹层）。层级靠表面色阶 + 发丝线（`--border` 8%/9% 透明度）表达，不靠阴影堆叠。
2. **`--primary` 与 `--brand` 分离**：主按钮保持中性高对比（白底黑字/黑底白字）；`--brand` 只用于稀缺强调——当前会话行、链接、运行态、focus ring、发送按钮、开关/复选框选中态。
3. **语义状态色**：`success` / `warning` / `destructive` 三个令牌，深浅主题各自取值，组件里禁止再写 `amber-500` 这类调色板字面量。
4. **中文排版**：字体栈 `Geist Variable → PingFang SC → {{SECRET_9hy8av6j}} UI → Noto Sans SC`；正文 15px/1.7，控件与列表 13px，元数据下限 12px，**禁止 10/11px 中文**。
5. **动效稀缺而一致**：全部走 `--ease-standard` 与统一时长；进场与折叠动画在 `prefers-reduced-motion` 下自动归零。

## 圆角 / 阴影 / 动效

- 圆角四档：6（控件）· 8（输入框）· 10（按钮）· 14（卡片/弹窗）· 20（composer/用户气泡）。
- 阴影：`shadow-card`（浅色外投影 4%、深色内高光 4%）、`shadow-pop`、`shadow-dialog`；只在浮层用真阴影。
- 动效：默认过渡 180ms（`--default-transition-duration`），`--ease-standard: cubic-bezier(0.2,0,0,1)`；消息进场 `wb-message-in`（opacity+4px，180ms）；折叠展开用 grid-rows `0fr→1fr`（200ms）；reduced-motion 全局归零。

## 组件模式

- **页面**：`PageShell`（max-w-5xl / px-8 py-7）+ `PageHeader`（20px 标题/13px 描述/右对齐动作）+ `Section`；设置行用 `SettingRow`。
- **对话解剖**：助手 = 无气泡全宽正文（作者行 12px）；用户 = 品牌底色气泡（20px 圆角，max-w 640，操作图标收在区块右下角）；执行组 = 平面容器 + 发丝线分行，组内工具行 `flat` 无描边；确认卡 = 左侧 2px 语义色条 + 10% 底色；思考过程 = 左竖线 + 静音文字。
- **管理页列表**：单列行式（图标块 + 名称/元信息 + 徽章 + 右侧动作），删除用 28px ghost 图标 + `aria-label`。
- **代码块**：`bg-muted/40` 独立底、无描边、语言标签 + 悬停复制，内置零依赖高亮（kw/str/num/com 四类）。
- **空态**：品牌圆形图标 + 15px 标题 + 13px 说明 + 主按钮，垂直居中。
