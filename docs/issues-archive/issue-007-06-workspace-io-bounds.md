### What to build

Agent 读取工作区大文件时在读到上限后立即停止并标记截断；产物预览打开大文本文件同样有内存上限；模型单次写入工作区的内容超过上限时收到明确错误。工作区里放超大文件不再威胁应用进程内存。

### Acceptance criteria

- [ ] 文件读取工具对超过上限的文件返回截断内容（UTF-8 不截半字符），且不再整文件载入内存
- [ ] 产物预览文本分支同样有界读取，截断标记正确
- [ ] 写入工具超上限返回明确错误；上限内写入行为不变
- [ ] 上述行为均有以真实大文件驱动的测试（不依赖内存指标）
